# Multi-Tool Adapters Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the agent-team workflow run inside Codex CLI, Cursor and Gemini CLI from one tool-neutral role source, with the models the owner declares per tool.

**Architecture:** Each core role is written once in `roles/`. A new standard-library package `scripts/team_adapt/` renders those sources:
- **Claude Code:** the plugin's own `agents/` and `skills/agent-team/SKILL.md`, committed in this repo. A drift test keeps them equal to the generator's output.
- **Codex, Cursor and Gemini:** one agent file per role and tier, a shared lead skill in `.agents/skills/agent-team/`, and a marked block in `AGENTS.md`/`GEMINI.md`. These are written into a project by `scripts/team-adapt`.

`team.json` validation learns every tool block.

**Tech Stack:** Python 3.9+ standard library only, `unittest`.

**Spec:** `docs/specs/2026-11-17-multi-tool-adapters-design.md`.

## Global Constraints

- Python 3.9+, standard library only. No new dependency.
- Run all tests: `cd tests && PYTHONPATH=../scripts python3 -m unittest`. Baseline: `Ran 238 tests`, `OK`.
- Run one module: `cd tests && PYTHONPATH=../scripts python3 -m unittest test_config -v`.
- Every test is seen failing before the code that passes it. Commit after each task.
- Tools allowed under `tiers`: `claude-code`, `codex`, `cursor`, `gemini`. Every block names all four tiers: `strongest`, `strong`, `standard`, `fast`. `version` stays 1.
- Claude Code behaviour must not change. The only allowed difference in `agents/*.md` and `skills/agent-team/SKILL.md` is the added marker comment line.
- Marker text: `Generated by agent-team team-adapt from <source>. Do not edit; edit the source and rerun team-adapt.`
- `team-adapt` writes nothing when it finds a problem. It overwrites or deletes only files that carry the marker.
- Instruction-file block markers: `<!-- agent-team:start -->` and `<!-- agent-team:end -->`. Text outside them is never changed.
- Non-Claude agent names: `<role>-<tier>`, for example `builder-standard`.

## Rulings made while planning

1. **Marker placement.** In YAML front matter, the marker is a `#` comment on the line after the opening `---`, because the front matter must stay first. In TOML it is the first line. In copied markdown (`rules.md`) it is an HTML comment on the first line.
2. **All four tiers per role.** Every role gets all four tiers, because a reviewer on `strongest` can move down to `strong` (spec section 7, now corrected).
3. **Templates read from the clone.** The non-Claude skill reads the templates from the agent-team clone by absolute path instead of copying them, so the marker never lands in a plan (spec section 6, now corrected).
4. **Line tags instead of `{{start_agent role tier}}`.** The spec's placeholder becomes two things: `{{agent <role>}}`, because the tier is resolved at run time, and the line tags `{{claude}}` and `{{other}}` for sentences that differ by tool.

## Review Focus

1. The drift test truly compares the committed Claude files with fresh generator output, and `claude plugin validate` still passes with the marker comment in the front matter.
2. No file is written when any problem is found, including a half block in `AGENTS.md`.
3. Stale-file deletion never removes a file without the marker.
4. TOML and YAML escaping of descriptions and bodies: quotes, colons and new lines.

```python
    if not isinstance(tiers, dict) or not tiers:

    problems = []
    for tool in sorted(tiers):
        block = tiers[tool]
        if tool not in TOOLS:

        elif not isinstance(block, dict):
            problems.append("tiers.%s must map tier names to models" % tool)
```

```python
"""The line that marks a file as written by team-adapt (spec section 5.2)."""

SIGNATURE = "Generated by agent-team team-adapt"
TEXT = SIGNATURE + " from %s. Do not edit; edit the source and rerun team-adapt."
HEAD_LINES = 3


def hash_line(source):
    return "# " + TEXT % source


def html_line(source):
    return "<!-- " + TEXT % source + " -->"


def after_first_line(text, line):
    """Answer text with line inserted after its first line (inside YAML front matter)."""
    first, rest = text.split("\n", 1)
    return first + "\n" + line + "\n" + rest


def is_generated(text):
    return SIGNATURE in "\n".join(text.split("\n")[:HEAD_LINES])
```

`scripts/team_adapt/source.py`:

```python
"""Read the tool-neutral role sources in roles/ (spec section 5.1)."""
import os
from collections import namedtuple

REPO_ROOT = os.path.dirname(os.path.dirname(os.path.dirname(os.path.realpath(__file__))))
AGENT_ROLES = ("builder", "code-reviewer", "security-reviewer", "plan-reviewer", "doc-recorder")
NEUTRAL_TOOLS = ("read", "edit", "write", "shell", "search")
FIELDS = ("name", "description", "read-only", "tools")

Role = namedtuple("Role", "name description read_only tools body")


def read_text(path):
    with open(path, encoding="utf-8") as handle:
        return handle.read()


def split_front_matter(text, path):
    """Answer (fields, body) for text that starts with '---' front matter of 'key: value' lines."""
    if not text.startswith("---\n") or "\n---\n" not in text[3:]:
        raise ValueError("%s: no front matter" % path)
    head, body = text[4:].split("\n---\n", 1)
    fields = {}
    for line in head.split("\n"):
        key, sep, value = line.partition(": ")
        if not sep:
            raise ValueError("%s: bad front matter line: %s" % (path, line))
        fields[key] = value
    return fields, body


def read_role(name, repo_root=REPO_ROOT):
    path = os.path.join(repo_root, "roles", name + ".md")
    fields, body = split_front_matter(read_text(path), path)
    if any(key not in fields for key in FIELDS) or fields["name"] != name or fields["read-only"] not in ("true", "false"):
        raise ValueError("%s: needs name %s, description, read-only true or false, and tools" % (path, name))
    tools = tuple(tool.strip() for tool in fields["tools"].split(","))
    unknown = [tool for tool in tools if tool not in NEUTRAL_TOOLS]
    if unknown:
        raise ValueError("%s: unknown tools: %s" % (path, ", ".join(unknown)))
    return Role(name, fields["description"], fields["read-only"] == "true", tools, body)


def read_roles(repo_root=REPO_ROOT):
    return [read_role(name, repo_root) for name in AGENT_ROLES]


def read_lead(repo_root=REPO_ROOT):
    return read_text(os.path.join(repo_root, "roles", "lead.md"))
```

`scripts/team_adapt/render.py`:

```python
"""Fill the lead skill for one tool family (spec section 5.1; line tags per plan ruling 4)."""
import re

FAMILIES = ("claude", "other")
LINE_TAG = re.compile(r"^\{\{(claude|other)\}\} ?")
AGENT = re.compile(r"\{\{agent ([a-z-]+)\}\}")
AGENT_NAME = {"claude": "`agent-team:%s`", "other": "`%s-<tier>`"}


def render(text, family, plugin_root):
    """Keep untagged lines and lines tagged for this family, then fill the placeholders."""
    if family not in FAMILIES:
        raise ValueError("unknown family: %s" % family)
    kept = []
    for line in text.split("\n"):
        tag = LINE_TAG.match(line)
        if tag and tag.group(1) != family:
            continue
        kept.append(line[tag.end():] if tag else line)
    out = AGENT.sub(lambda match: AGENT_NAME[family] % match.group(1), "\n".join(kept))
    return out.replace("{{templates}}", plugin_root + "/templates").replace("{{plugin_root}}", plugin_root)
```

`scripts/team_adapt/claude.py`:

```python
"""Claude Code output: the plugin's own agents/ and skills/agent-team/SKILL.md (spec section 6)."""
import json
import os

from team_adapt import marker, render, source

PLUGIN_ROOT = "${CLAUDE_PLUGIN_ROOT}"
SKILL = os.path.join("skills", "agent-team", "SKILL.md")
TOOL_NAMES = {"read": ["Read"], "edit": ["Edit"], "write": ["Write"], "shell": ["Bash"], "search": ["Grep", "Glob"]}


def agent_file(role, model):
    tools = ", ".join(name for tool in role.tools for name in TOOL_NAMES[tool])
    head = "---\n%s\nname: %s\ndescription: %s\ntools: %s\nmodel: %s\n---\n" % (
        marker.hash_line("roles/%s.md" % role.name), role.name, role.description, tools, model)
    return head + role.body


def skill_file(lead_text):
    return marker.after_first_line(render.render(lead_text, "claude", PLUGIN_ROOT), marker.hash_line("roles/lead.md"))


def template_models(repo_root=source.REPO_ROOT):
    """Answer role -> model from templates/team.json; it fills each agent file's fallback model line."""
    with open(os.path.join(repo_root, "templates", "team.json"), encoding="utf-8") as handle:
        cfg = json.load(handle)
    models = cfg["tiers"]["claude-code"]
    return {role: models[tier] for role, tier in cfg["roles"].items()}


def plugin_outputs(repo_root=source.REPO_ROOT):
    """Answer {path relative to the repo: text} for every Claude Code file the plugin ships."""
    models = template_models(repo_root)
    outputs = {
        os.path.join("agents", role.name + ".md"): agent_file(role, models[role.name])
        for role in source.read_roles(repo_root)
    }
    outputs[SKILL] = skill_file(source.read_lead(repo_root))
    return outputs


def write_plugin_files(repo_root=source.REPO_ROOT):
    outputs = plugin_outputs(repo_root)
    for rel, text in outputs.items():
        with open(os.path.join(repo_root, rel), "w", encoding="utf-8") as handle:
            handle.write(text)
    return sorted(outputs)
```

```python
    roles = source.read_roles(repo_root) if tools else []
    for tool in tools:
        module = MODULES[tool]

                path = os.path.join(module.AGENT_DIR, name + module.EXTENSION)
```

```python
"""Write team-adapt's output into a project, all or nothing (spec sections 6 and 10)."""
import os

from team_adapt import marker

START = "<!-- agent-team:start -->"
END = "<!-- agent-team:end -->"


def with_block(text, block):
    """Answer text with the agent-team block replaced, or appended if absent."""
    start, end = text.find(START), text.find(END)
    full = START + "\n" + block + END
    if start != -1 and end > start:
        return text[:start] + full + text[end + len(END):]
    if start != -1 or end != -1:
        raise ValueError("has only one of the agent-team markers")
    gap = "" if not text else ("\n" if text.endswith("\n") else "\n\n")
    return text + gap + full + "\n"


def _read(path):
    """Answer the file's text, or None when it does not exist; raise OSError or UnicodeDecodeError otherwise."""
    try:
        with open(path, encoding="utf-8") as handle:
            return handle.read()
    except FileNotFoundError:
        return None


def plan_changes(project_dir, files, blocks, generated_dirs):
    """Answer (writes, deletes, problems) without touching the disk."""
    writes, problems = {}, []
    for rel, text in sorted(files.items()):
        try:
            current = _read(os.path.join(project_dir, rel))
        except (OSError, UnicodeDecodeError):
            problems.append("%s cannot be read" % rel)
            continue
        if current is not None and not marker.is_generated(current):
            problems.append("%s exists and was not written by team-adapt" % rel)
        writes[rel] = text
    for rel, block in sorted(blocks.items()):
        try:
            writes[rel] = with_block(_read(os.path.join(project_dir, rel)) or "", block)
        except (OSError, UnicodeDecodeError):
            problems.append("%s cannot be read" % rel)
        except ValueError as error:
            problems.append("%s %s" % (rel, error))
    deletes = [rel for rel in _generated_files(project_dir, generated_dirs) if rel not in files]
    return writes, deletes, problems


def _generated_files(project_dir, generated_dirs):
    found = []
    for rel_dir in generated_dirs:
        folder = os.path.join(project_dir, rel_dir)
        if not os.path.isdir(folder):
            continue
        for name in sorted(os.listdir(folder)):
            rel = os.path.join(rel_dir, name)
            path = os.path.join(project_dir, rel)
            if not os.path.isfile(path):
                continue
            try:
                text = _read(path)
            except (OSError, UnicodeDecodeError):
                continue
            if text is not None and marker.is_generated(text):
                found.append(rel)
    return found


def apply(project_dir, writes, deletes):
    for rel, text in sorted(writes.items()):
        path = os.path.join(project_dir, rel)
        os.makedirs(os.path.dirname(path), exist_ok=True)
        with open(path, "w", encoding="utf-8") as handle:
            handle.write(text)
    for rel in deletes:
        os.remove(os.path.join(project_dir, rel))
```

```python
"""team-adapt: write each tool's agent-team files into a project (multi-tool adapters spec)."""
import argparse
import os
import sys

from team_adapt import claude, project, write
from team_status import config

CURSOR_READS_CODEX = (
    "warning: Cursor also reads .codex/agents/ and may load agents with Codex model names; "
    "check which agent Cursor starts"
)


def main(argv, out=sys.stdout, err=sys.stderr):
    parser = argparse.ArgumentParser(prog="team-adapt", description="Write Codex, Cursor and Gemini agent-team files.")
    parser.add_argument("project", nargs="?", default=".", help="project folder (default: current folder)")
    parser.add_argument("--plugin", action="store_true", help="regenerate this plugin's own Claude Code files")
    args = parser.parse_args(argv)
    if args.plugin:
        for rel in claude.write_plugin_files():
            print("wrote %s" % rel, file=out)
        return 0
    return adapt(os.path.abspath(args.project), out, err)


def adapt(project_dir, out, err):
    cfg, problems = config.load_config(project_dir)
    if problems:
        for problem in problems:
            print("team.json: %s" % problem, file=err)
        return 1
    files, blocks = project.project_outputs(cfg)
    writes, deletes, problems = write.plan_changes(project_dir, files, blocks, project.GENERATED_DIRS)
    if problems:
        for problem in problems:
            print(problem, file=err)
        print("nothing written", file=err)
        return 1
    if not writes and not deletes:
        print("nothing to write: no codex, cursor or gemini block under tiers", file=out)
        return 0
    try:
        write.apply(project_dir, writes, deletes)
    except OSError as error:
        print("stopped while writing, some files may be written: %s" % error, file=err)
        return 1
    for rel in sorted(writes):
        print("wrote %s" % rel, file=out)
    for rel in deletes:
        print("deleted %s" % rel, file=out)
    if "codex" in cfg["tiers"] and "cursor" in cfg["tiers"]:
        print(CURSOR_READS_CODEX, file=err)
    return 0
```

```python
"""team-adapt --init: ask for tools, models and project values, then write .claude/team.json (spec section 9)."""
import copy
import json
import os

from team_adapt import source
from team_status import config


def _ask_text(ask, prompt):
    while True:
        answer = ask(prompt).strip()
        if answer:
            return answer


def _ask_tools(ask):
    prompt = "Tools you use (%s), comma separated: " % ", ".join(config.TOOLS)
    while True:
        tools = [tool.strip() for tool in ask(prompt).split(",") if tool.strip()]
        if tools and all(tool in config.TOOLS for tool in tools):
            return list(dict.fromkeys(tools))


def _ask_checks(ask):
    checks = []
    while True:
        name = ask("Check name, for example tests (blank to finish): ").strip()
        if name:
            checks.append({"name": name, "run": _ask_text(ask, "Command for %s: " % name)})
        elif checks:
            return checks


def build_config(ask, template):
    """Answer a new config: the template with the owner's tools, models, owner, checks and paths."""
    cfg = copy.deepcopy(template)
    cfg["tiers"] = {
        tool: {tier: _ask_text(ask, "%s model for the %s tier: " % (tool, tier)) for tier in config.TIER_NAMES}
        for tool in _ask_tools(ask)
    }
    cfg["owner"] = _ask_text(ask, "Owner name: ")
    cfg["checks"] = _ask_checks(ask)
    for key in ("plans", "routing-log"):
        answer = ask("paths.%s [%s]: " % (key, cfg["paths"][key])).strip()
        if answer:
            cfg["paths"][key] = answer
    return cfg


def run_init(project_dir, ask=input, out=print):
    """Ask the questions and write .claude/team.json; answer whether a new file was written."""
    path = os.path.join(project_dir, config.CONFIG_PATH)
    if os.path.exists(path) and ask("%s exists. Replace it? [y/N] " % config.CONFIG_PATH).strip().lower() != "y":
        out("kept %s" % config.CONFIG_PATH)
        return False
    with open(os.path.join(source.REPO_ROOT, "templates", "team.json"), encoding="utf-8") as handle:
        template = json.load(handle)
    cfg = build_config(ask, template)
    problems = config.validate(cfg)
    if problems:
        for problem in problems:
            out("team.json: %s" % problem)
        return False
    os.makedirs(os.path.dirname(path), exist_ok=True)
    with open(path, "w", encoding="utf-8") as handle:
        json.dump(cfg, handle, indent=2)
        handle.write("\n")
    out("wrote %s" % config.CONFIG_PATH)
    return True
```
